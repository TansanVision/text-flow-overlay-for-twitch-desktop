# チャンネルポイント演出

## 実装済みの演出

- **ふわふわハート**: 10秒間、大小・6色のハートが画面下から次々に浮かび上がり、個別に薄くなって消える。コメントの投稿は不要。旧「次のコメントに光の軌跡」の報酬・設定は自動的にハートへ引き継ぐ。Twitch側の名称は「報酬を更新」で変更できる。光の軌跡とコメント待ちは廃止。
- **10秒の無重力**: 10秒間、新しく届くコメントがゆっくり上下する。既存のコメントの流れ方と表示時間は維持する。
- **花のじゅうたん**: 画面下いっぱいに大小・6色の花が前後2列に咲き広がり、ゆっくり揺れて12秒で消える。画面幅に合わせて本数を調整し、高さは画面の約2割以内に収める。旧「一輪の花」の報酬でも新しい演出になる。Twitch側の名称は「報酬を更新」で変更できる。

- **エモート噴水**: 8秒間、登録済みカスタムスタンプが画面下の3か所から合計84個噴き上がり、回転しながら弧を描いて落ちる。異なる画像を最大24種類使用し、未登録や画像の読み込み失敗時は内蔵スマイルで表示する。チャットの投稿は不要。カスタムスタンプの通常・落下設定にかかわらず、噴水の動きで表示する。

- **お祝い花火**: 10秒間、左右から6発の色とりどりの花火が順番に上がり、最後に中央で金色の大輪が開く。二重の光の粒が広がり、余韻を残しながら落ちて消える。音声・名前表示・コメントの投稿は不要。

- **シャボン玉**: 10秒間、大小64個のシャボン玉が画面下から順番に浮かび上がる。左右に揺れながら半透明の虹色の膜がきらめき、それぞれ違う高さで小さな光の粒になって弾ける。名前表示やコメントの投稿は不要。

- **ペイント遊び**: 10秒間、6色・大小20個の絵の具が画面のあちこちに飛び散る。丸みのあるしぶきがぷるんと広がり、少し垂れてから順番に薄くなって消える。名前表示やコメントの投稿は不要。

- **流星群**: 10秒間、青白い光や淡い紫の尾を引く48個の流れ星が右上から左下へ流れ、最後に金色の大きな流れ星が横切る。周囲では36個の小さな星が順番にきらめく。背景は透明で、名前表示やコメントの投稿は不要。

追加予定だったエモート噴水・お祝い花火・シャボン玉・ペイント遊び・流星群の5種類を実装済み。

## 利用手順

1. コントロールパネルの「チャンネルポイント演出」で「ポイント管理を許可して接続」を押し、Twitchで追加認証する。
2. オーバーレイを表示し、各演出の「テスト表示」で確認する。テストは認証不要で、ポイントやTwitchの報酬を変更しない。
3. 必要ポイント・クールダウンを設定し、「Twitchに報酬を作成」を押す。初期状態では受付は無効。
4. 準備ができたら「Twitchで受付を有効にする」を選び、「報酬を更新」する。
5. Twitchで実際に引き換え、表示と「最近の演出」の処理状態を確認する。
6. アプリ終了・ログアウト前に受付を無効にして更新する。アプリ終了だけではTwitch上の報酬は無効にならない。

報酬作成はチャンネルポイントを利用できる配信者アカウントが対象。通常のチャット認証には追加権限を要求しない。ポイント機能を選んだ場合だけ `channel:manage:redemptions` を追加する。

## 待機・通信障害時

- アプリが作成した報酬だけを管理する。他アプリ・手動作成の報酬は変更しない。
- 演出は1件ずつ順番に再生する。Raid・クリップ中は開始を待ち、再生中なら演出の時間を一時停止する。
- 待機は引き換えから最大2分。再生開始後も2分以内に完了応答がなければ取消・返還を試行する。長いRaidによってもこの上限に達する場合がある。
- 混雑時（待機・再生が50件以上）や無効な報酬は返還対象。テストは同時に5件まで。
- 完了応答を受けてからTwitchへ `FULFILLED` を送る。取消時は `CANCELED` を送る。通信障害中は「完了を送信中」「ポイント返還待ち」を維持し、30秒後に再試行する。Twitchが成功を確認するまで完了・返還済みと表示しない。
- 応答を失った場合はTwitch側の状態を照合する。Twitch側ですでに完了・取消されたものを再実行しない。
- 30秒ごとに各報酬の未処理引き換えを古い順に最大50件取得し、切断中の取りこぼしを補う。50件を超える場合は処理が進むにつれて後続を取得する。古い引き換えは再生せず返還する。
- 再起動時、保存済みの待機・再生中の引き換えは返還対象とする。保存済みの完了送信待ちは再送する。処理には元の配信者・同じClient IDでの認証が必要。
- 記録は `portable-data/config/channel-points.json`。報酬ID・引き換えID・ユーザーID・処理状態を保存する。トークンは含めない。処理中はこのファイルを削除しない。
- 記録は一時ファイルへの書き込み・同期後に置換する。保存失敗時は状態を進めず、完了応答を再試行可能にする。完了済み履歴は最大100件、未処理の返還・完了送信は保持する。

## 検証範囲

自動テストで旧報酬からの移行・ハートの10秒再生・重複通知・他チャンネル除外・順番待ち・待機超過・再起動・保存失敗・取消と遅延応答の競合・Raid中断・追加認証・設定画面のAPIエラー表示を確認する。実際のTwitch報酬作成とポイント返還は、利用資格のあるアカウントでの確認が必要。

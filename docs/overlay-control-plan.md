# オーバーレイ制御機能の実装候補

## この文書の位置付け

管理画面からOBS用オーバーレイを操作する機能について、将来の実装候補を整理する。

現時点では検討事項であり、この文書に記載したボタンや制御機能はまだ実装しない。実装の必要性と操作方法を決めた後、段階的に追加する。

## 現在の動作

アプリ起動時に次の2ウィンドウを生成する。

- `control-panel`: 通常の管理画面
- `overlay`: OBSがウィンドウキャプチャする透明画面

`overlay`には現在、次の設定を適用している。

- 背景透明
- ウィンドウ枠なし
- 1280×720
- タスクバーに表示しない
- マウス操作を透過
- OBSから独立したウィンドウとして取得可能

オーバーレイは最前面に固定していないため、別のウィンドウの背後へ移動するとデスクトップ上では見えなくなる。一方、OBSのウィンドウキャプチャには継続して表示される。この状態は現在の配信モードとして扱う。

## 実装可能な操作

TauriのウィンドウAPI、Rust command、またはウィンドウ間イベントを使用することで、管理画面から次の操作を実装できる。

- オーバーレイ描画のON／OFF
- オーバーレイウィンドウの表示／非表示
- 最前面への移動
- クリック透過のON／OFF
- ウィンドウ位置の変更
- ウィンドウサイズ・解像度の変更
- テストコメントやテストエフェクトの表示
- オーバーレイだけを再読み込み
- クリップ音量・ミュートの変更
- OBSモードと編集モードの切り替え

## 「非表示」の違い

管理画面では目的に応じて操作を分ける必要がある。

| 操作 | デスクトップ | OBS | 用途 |
| --- | --- | --- | --- |
| 背面へ移動 | 見えにくくなる | 映る | 通常の配信 |
| クリック透過ON | 下のアプリを操作可能 | 映る | 通常の配信 |
| Reactの描画をOFF | 透明になる | 透明になる | OBSの取得対象を維持した一時非表示 |
| Tauriウィンドウを`hide()` | 見えない | 原則映らない | 完全な非表示 |
| Tauriウィンドウを閉じる | 見えない | 映らない | オーバーレイの終了 |

OBSがキャプチャ対象を見失う可能性を減らすため、配信中の一時非表示にはウィンドウの`hide()`ではなく、React側の描画ON／OFFを使うことを推奨する。

## 検討する操作モード

### 配信モード

- クリック透過ON
- タスクバー非表示
- 最前面固定なし
- OBSのキャプチャ対象を維持
- 管理画面の終了時はアプリ全体を終了

現在のオーバーレイは、概ねこの状態で起動する。

### 編集モード

- クリック透過OFF
- 必要に応じて最前面へ表示
- オーバーレイの境界を一時的に表示
- ドラッグによる位置調整
- サイズまたは解像度の変更
- 調整終了後に配信モードへ戻す

### テストモード

- テストコメントを表示
- Twitchエモートの代替データを表示
- 桜、雪、風船などの各エフェクトを確認
- Raidイントロとクリップ領域を確認
- コンパネの「デスクトップへ戻す／画面外へ移動」でウィンドウ位置を切り替えられる
- 画面外待避はウィンドウを非表示にせず座標`(-10000, -10000)`へ移すため、OBSのウィンドウソースを維持できる
- 一定時間後に自動で通常表示へ戻す

## 管理画面の候補

将来の管理画面には、次の操作を候補とする。

1. `オーバーレイ描画 ON/OFF`
2. `配信モード`
3. `編集モード`
4. `テストコメント表示`
5. `オーバーレイ再読み込み`
6. 解像度選択
   - 1280×720
   - 1920×1080
   - 2560×1440
7. クリップ音量とミュート

ボタンを実装する前に、設定を即時反映するか、`適用`ボタンでまとめて反映するかを決定する。

## 技術的な構成案

```text
管理画面
  ↓ Tauri command / event
Rust側のウィンドウ制御
  ├─ 表示・非表示
  ├─ 位置・サイズ
  ├─ クリック透過
  └─ 最前面設定

管理画面
  ↓ Tauri event
オーバーレイReact画面
  ├─ 描画ON／OFF
  ├─ テスト表示
  ├─ エフェクト設定
  └─ クリップ音量
```

ウィンドウ自体の操作はRust側、Reactコンテンツの操作はオーバーレイrenderer側へ分ける。

## 実装前に決める事項

- 日常利用で編集モードが必要か
- 位置調整はOBS側だけで行うか、アプリ側でも行うか
- 解像度を固定するか選択式にするか
- 描画OFFの状態を再起動後も保存するか
- オーバーレイを誤って閉じた場合に自動再生成するか
- テストコメントの文面・表示時間
- クリップ音量をアプリ側とOBS側のどちらで管理するか

これらを決定してから、必要最小限の操作から実装する。

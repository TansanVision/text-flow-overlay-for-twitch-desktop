# モデレーション同期

Twitchで削除されたコメントを、オーバーレイからも取り除く。接続時に自動で有効になり、追加の設定は不要。

## 対応する操作

| Twitch側の操作 | オーバーレイの動作 |
| --- | --- |
| コメント1件を削除 | 同じメッセージIDのコメントを消す |
| ユーザーをタイムアウト・BAN | そのユーザーIDの、削除通知の時刻以前のコメントを消す |
| チャット全消去 | 対象チャンネルの、削除通知の時刻以前のコメントを消す |

コメントから発生した組み込みエフェクト・落下スタンプ・`!helpcs`の表示と待機列も同時に取り除く。同じ表示名の別ユーザーは対象にならない。タイムアウト終了後など、削除通知より後の新しいコメントは通常どおり表示する。

対象はチャット由来の表示。独立したRaid紹介、Bits・サブスク・ギフト通知、コンパネのテスト表示、反応ユーザーの記録は対象外。

## 受信と再接続

- `channel.chat.message_delete`、`channel.chat.clear_user_messages`、`channel.chat.clear`を既存のEventSub接続で購読する。
- 現在使用している`user:read:chat`権限で受信できる。モデレーター操作をアプリから実行する権限は追加しない。
- 通常の再接続では購読を作り直し、Twitch指定の接続切り替えでは購読を引き継ぐ。
- 削除済みID・ユーザーやチャンネルごとの削除時刻を10分間・合計最大10,000件、画面のメモリ内に保持する。通知の前後や再接続で古いコメントが届いても、この範囲で再表示を抑止する。
- 時刻はTwitchの通知時刻をUTC・ナノ秒精度で比較する。同じミリ秒内でも削除後に投稿されたコメントを区別する。
- 購読に失敗した場合、コンパネの「コメント削除・モデレーション同期」警告で確認できる。「今すぐ再接続」で購読を再試行する。

アプリが起動していない間や通信切断中の削除通知は復元できない。アプリ再起動時に削除履歴は消える。

## 実機確認

表示時間を長めに設定し、確認用アカウントから投稿して、配信者またはモデレーターがTwitch側で操作する。

1. コメントを2件投稿し、1件だけ削除する。対象だけが消えることを確認する。
2. `snow 確認`のコメントを削除し、本文と雪のエフェクトが消えることを確認する。
3. 同じユーザーから複数投稿し、短時間のタイムアウトを行う。そのユーザーの表示が消え、別ユーザーの表示が残ることを確認する。
4. タイムアウト終了後に再投稿し、新しいコメントが表示されることを確認する。
5. チャット全消去を行い、表示中のコメントが消えることを確認する。その後の投稿は表示される。
6. 再接続後も、コメント削除が反映されることを確認する。

自動テストでは、上記の削除判定に加え、通知の順序逆転・重複、別チャンネル、表示待ちの一覧、履歴の上限と有効期限、購読失敗の警告を確認する。実際のTwitchでのモデレーション操作は別途確認が必要。

参照: [EventSub Subscription Types](https://dev.twitch.tv/docs/eventsub/eventsub-subscription-types/)、[EventSub Reference](https://dev.twitch.tv/docs/eventsub/eventsub-reference/#channel-chat-clear-user-messages-event)。

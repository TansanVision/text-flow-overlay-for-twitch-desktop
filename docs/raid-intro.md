# Raid紹介

Raid紹介には自動紹介と手動紹介がある。コンパネの「Raidクリップ設定」から選択する。

## 自動紹介

Raidを受信すると、次の順序で紹介を実行する。

1. Raid元ユーザーのプロフィール画像、表示名、Raid人数を60秒表示する
2. Twitch Clips APIから取得したクリップを最大5件、各クリップの実時間で再生する
3. クリップ終了後、Twitch Shoutout APIでRaid元ユーザーをシャウトアウトする

## 手動紹介

1. Raid元ユーザーのプロフィール画像、表示名、Raid人数を設定時間だけ表示する
2. イントロ終了後、オーバーレイを閉じる
3. コンパネへRaid元ユーザーのカードと「シャウトアウト」ボタンを表示する
4. 配信者が口頭で紹介を行う
5. 紹介後にボタンを押し、Twitch Shoutout APIでシャウトアウトする

手動紹介ではクリップの自動再生と自動シャウトアウトを行わない。送信に失敗したカードは残るため再実行できる。複数のRaidを受けた場合はカードをキューとして保持する。

上記は既定値であり、コンパネの「Raidクリップ設定」からイントロ時間、再生本数、クリップ音声、自動シャウトアウトを変更できる。クリップが取得できなかった場合はイントロ終了後にシャウトアウトへ進む。

旧形式の`portable-data/config/overlay.json`は、初回読み込み時に新しい既定値へ一度だけ移行される。移行後にコンパネで変更した設定は維持される。

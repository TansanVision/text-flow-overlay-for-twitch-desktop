# カスタムフォント

コメント表示設定では、標準フォントとカスタムフォントを同じドロップダウンから選択できる。

カスタムフォントは、実行ファイルと同じ場所に作られる`portable-data/fonts`へ配置する。対応形式はTTF、OTF、WOFF、WOFF2。サブフォルダは読み込まず、フォントファイルは`fonts`直下へ配置する。

コンパネの「フォントフォルダを開く」で配置先を開き、ファイルを追加または削除した後に「フォント一覧を再読み込み」を押す。正常に読み込めたフォントは、コメントフォントの「カスタムフォント」グループへファイル名で追加される。

選択中のカスタムフォントが削除された、または読み込めなかった場合は、システム標準フォントへ戻る。

フォントファイルをアプリと一緒に配布する場合は、各フォントの再配布ライセンスを確認すること。日本語グリフを収録していないフォントでは、未収録の文字に代替フォントが使われる。

# コントロールパネル

左メニューで目的別に画面を切り替えます。追加のUIライブラリは使用せず、既存のReact・CSSと標準のボタン・折りたたみ要素で構成しています。

| メニュー | 操作・設定 |
| --- | --- |
| 配信操作 | オーバーレイの画面内／画面外切り替え、テストコメント、手動Raid対応、広告操作、Creator Dashboard |
| コメント表示 | 文字サイズ・表示時間・フォント、カスタムフォント、内蔵エフェクトの受付 |
| Raid・クリップ | 紹介モード・表示時間・クリップ本数・シャウトアウト |
| ポイント演出 | 演出の選択、テスト、必要ポイント・クールダウン・受付の設定、処理履歴 |
| 素材 | カスタムスタンプ、外部エモート |
| テスト・その他 | コメント・エフェクト・Raid・クリップのテスト、視聴者一覧、実行環境 |

## 表示と入力の扱い

- 認証・コメント受信の状態は全画面に表示します。再認証や接続エラーも同じ場所で確認できます。
- 再生中のクリップの状態とスキップ操作は、設定画面を切り替えても表示します。
- 手動Raidを受信すると「配信操作」に件数を表示し、別画面を開いている場合は移動ボタン付きの通知を表示します。
- メニュー切り替えでは入力内容を破棄しません。設定の保存方法は従来どおりで、未保存の入力をアプリ再起動後まで保持するものではありません。
- ポイント演出は一覧から選んだ1種類だけ設定フォームを表示します。演出やメニューを切り替えても、入力途中の値を保持します。
- 広告操作、カスタムフォント、内蔵エフェクト、外部エモート、視聴者一覧、実行環境、ポイント処理履歴などは見出しを押して開きます。
- アプリの標準サイズ（1000×700）と最小サイズ（720×480）に合わせて、余白や一覧の列数を調整します。
